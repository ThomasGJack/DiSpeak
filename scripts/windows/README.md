# Scripts Windows

Les scripts Windows ont ete deplaces ici pour alleger la racine du projet.

Point d'entree recommande:
- `README.md` (quick start racine)
- `docs/README.md` (tutoriels complets)

## Scripts principaux

- `start.bat` : gestionnaire principal (backend / serveur / frontend / tauri)
- `start.ps1` : equivalent PowerShell
- `start-tauri.bat` : demarrage Tauri
- `start-tauri.ps1` : demarrage Tauri PowerShell
- `create-test-server.bat` : script de creation de serveur de test via API

## Depuis la racine du projet

```bat
scripts\windows\start.bat
```

```powershell
.\scripts\windows\start.ps1
```
